# SmartDraw Analytics

Платформа аналитики и автоматизации ставок по стратегии **«Легальная Вилка»** (Ничья + Нечетный Тотал).

Десктопное приложение на Electron + Next.js 16 с локальной SQLite-базой данных. Работает полностью офлайн; справочник лиг можно обновить из открытого сетевого источника.

> ## Где скачать установщик?
> Готового `.exe` нет в репозитории — Windows-установщик не кросс-собирается из Linux. **Чтобы получить `.exe`/`.dmg`/`.AppImage` бесплатно за 15 минут через облачную сборку GitHub Actions — откройте [HOW-TO-BUILD.md](./HOW-TO-BUILD.md).** Там пошаговая инструкция с картинками путём: залить на GitHub → нажать Run workflow → скачать готовый установщик.

## Возможности

- **Прематч-сканнер** — расчёт вилки «Ничья + Нечет», фильтр по ROI ≥ 20% и кэфу фаворита ≥ 1.90, округление сумм кратно 50/100 ₽ (защита от санкций БК).
- **Калькулятор вилок и банк-менеджмент** — распределение флэта по формуле `S_draw = S·K_odd/(K_draw+K_odd)`, расчёт гарантийного возврата.
- **Лайв-хеджирование** — мониторинг с 55-й минуты, классификатор зон (🟢 зелёная / 🔴 опасная / 🟡 аномальная), калькулятор страховки на Точный Счёт при 2:0, 0:2, 3:1, 1:3. Снижает убыток слепой зоны с −100% до контролируемых −16…−17%.
- **Справочник лиг** — 46 лиг из ТЗ (36 whitelist + 10 blacklist) по 5 зонам.
- **Журнал** — история закрытых матчей с зафиксированным P&L и ROI.
- **Локальная БД** — все данные в SQLite на ПК пользователя. Экспорт/импорт JSON-бэкапа для переноса.
- **Сетевое обновление** — кнопка «Обновить справочник из сети» подтягивает актуальный каталог лиг из открытого JSON-источника.

## Разработка (веб-режим)

```bash
bun install
bun run dev          # Next.js dev server на http://localhost:3000
bun run lint         # проверка кода
bun run db:push      # применить схему Prisma к БД
```

## Запуск как десктоп (Electron dev)

```bash
bun run electron:dev
```

Запускает одновременно Next.js dev-сервер и Electron-окно, которое подключается к `http://127.0.0.1:3000`. База данных кладётся в `%APPDATA%/SmartDraw/smartdraw.db` (Windows), `~/Library/Application Support/SmartDraw/` (macOS) или `~/.config/SmartDraw/` (Linux).

## Сборка установщика .exe (Windows)

Сборка выполняется на машине разработчика (Windows, macOS или Linux с wine для cross-build).

```bash
# 1. Установить зависимости
bun install

# 2. Сгенерировать Prisma клиент
bun run db:generate

# 3. Собрать Next.js (standalone) и упаковать в .exe
bun run dist:win
```

Готовый установщик появится в `dist/SmartDraw-Setup-1.0.0.exe` (NSIS installer).

### Что входит в установщик

- Next.js standalone-сервер (со всеми зависимостями).
- Electron runtime.
- Prisma engine + сгенерированный клиент.
- Встроенный справочник лиг (46 лиг из ТЗ) — засевается автоматически при первом запуске.
- Пустая SQLite-БД создаётся при первом запуске в пользовательской директории.

### После установки

1. Запустите `SmartDraw Analytics` из меню Пуск / с рабочего стола.
2. При первом запуске приложение:
   - создаст файл БД в `%APPDATA%/SmartDraw/smartdraw.db`,
   - применит схему Prisma,
   - засеет справочник лиг из встроенного каталога.
3. Все введённые матчи, страховки и настройки сохраняются в локальной БД.
4. Для обновления справочника лиг откройте **Настройки → Локальная база данных → Обновить справочник из сети**.
5. Для переноса на другой ПК — **Экспорт в файл**, затем **Импорт из файла** на новом ПК.

## Сетевое обновление справочника

Эндпоинт `POST /api/leagues/sync?url=<URL>` загружает JSON-каталог лиг в формате:

```json
{
  "$schema": "smartdraw-leagues-catalog/v1",
  "version": 1,
  "updatedAt": "2025-01-01",
  "leagues": [
    {
      "country": "Аргентина",
      "name": "Примера Дивизион",
      "code": "AR-PrimeraA",
      "tier": "whitelist",
      "zone": "Латинская Америка",
      "avgDrawPct": 30,
      "avgUnder25Pct": 70,
      "notes": null
    }
  ]
}
```

По умолчанию используется публичный репозиторий. Можно указать свой URL в поле ввода. Если сеть недоступна — используется встроенный `public/leagues-catalog.json`.

## Математика (формулы из ТЗ)

| Параметр | Формула |
|---|---|
| ROI вилки | `ROI = (1/(1/K_draw + 1/K_odd) − 1) × 100%` |
| Ставка на Ничью | `S_draw = S × K_odd / (K_draw + K_odd)` |
| Ставка на Нечет | `S_odd = S × K_draw / (K_draw + K_odd)` |
| Гарантийный возврат | `R_prematch = S_draw × K_draw` |
| Сумма страховки | `S_hedge = R_prematch / K_live_correct_score` |
| Округление | кратно `roundingStep` (по умолчанию 50 ₽) |

**Классификатор зон:**
- 🟢 **Зелёная** — нечётный тотал ИЛИ ничья (зашло одно из плечей).
- 🔴 **Опасная** — чётный счёт, разница 2, тотал ≤ 4 (2:0, 0:2, 3:1, 1:3) — нужна страховка.
- 🟡 **Аномальная** — высокий чётный счёт (4:0, 4:2) — ждать 80+ минуты.
