# Как получить установщик SmartDraw Analytics (.exe / .dmg / .AppImage)

В этом репозитории **нет готового `.exe`**, потому что Windows-установщик нельзя кросс-собрать из Linux-окружения, где сейчас ведётся разработка. Но вы можете получить готовый установщик **бесплатно за 15 минут** через GitHub Actions — облачную сборку.

## Способ 1 (рекомендуемый): собрать через GitHub — бесплатно, 15 минут

GitHub предоставляет бесплатные CI-минуты (2000 мин/мес для публичных репозиториев — более чем достаточно). Workflow уже настроен в `.github/workflows/build-desktop.yml`.

### Шаг 1. Зарегистрируйтесь на GitHub
Если ещё нет аккаунта — на https://github.com/signup (бесплатно).

### Шаг 2. Создайте новый репозиторий
1. Нажмите **+** в правом верхнем углу → **New repository**.
2. Имя: `smartdraw-analytics` (или любое).
3. Тип: **Public** (бесплатная сборка) или **Private** (нужен GitHub Pro).
4. **НЕ** ставьте галочки "Add README" / ".gitignore" / "license" — пустой репозиторий.
5. Нажмите **Create repository**.

### Шаг 3. Залейте проект
Скачайте проект из этого окружения (или склонируйте, если у вас есть доступ), затем в папке проекта:

```bash
git init
git add .
git commit -m "SmartDraw Analytics — initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/smartdraw-analytics.git
git push -u origin main
```

### Шаг 4. Запустите сборку
1. В репозитории откройте вкладку **Actions**.
2. Слева выберите **Build Desktop App**.
3. Нажмите **Run workflow** → выберите платформу:
   - `windows` — для `.exe` (Windows 7/10/11)
   - `mac` — для `.dmg` (macOS)
   - `linux` — для `.AppImage` (Linux)
   - `all` — собрать всё сразу
4. Нажмите зелёную кнопку **Run workflow**.

### Шаг 5. Скачайте готовый установщик
1. Дождитесь окончания сборки (~10-15 минут для Windows).
2. Нажмите на завершённый workflow run.
3. В самом низу — раздел **Artifacts**.
4. Скачайте `SmartDraw-windows` (или другую платформу).
5. Внутри ZIP-архива — готовый `SmartDraw-Setup-1.0.0.exe`.

### Шаг 6. Установите и пользуйтесь
1. Распакуйте ZIP, запустите `SmartDraw-Setup-1.0.0.exe`.
2. Установите как обычную программу (можно выбрать папку).
3. Запустите **SmartDraw Analytics** из меню Пуск.
4. При первом запуске создастся локальная БД и засеется справочник лиг — всё автоматически.

## Способ 2: собрать локально на своей Windows-машине

Если у вас Windows и вы хотите собрать сами:

### Требования
- Windows 10/11 (64-bit)
- [Node.js 20+](https://nodejs.org/)
- [Bun](https://bun.sh/) (`powershell -c "irm bun.sh/install.ps1 | iex"`)
- [Git](https://git-scm.com/)
- ~2 ГБ свободного места

### Команды
```powershell
git clone https://github.com/ВАШ_ЛОГИН/smartdraw-analytics.git
cd smartdraw-analytics
bun install
bun run db:generate
bun run dist:win
```

Готовый установщик появится в `dist/SmartDraw-Setup-1.0.0.exe`.

## Способ 3: запустить в режиме разработки (без сборки)

Если хотите проверить приложение прямо сейчас, не собирая установщик:

### На Windows/macOS/Linux с установленным Bun:
```bash
bun install
bun run electron:dev
```

Откроется окно приложения с hot-reload. БД создастся в пользовательской директории автоматически.

### Только веб-режим (без Electron):
```bash
bun install
bun run dev
```
Откройте http://localhost:3000 в браузере. Все функции работают, но это не десктоп-приложение.

## Что входит в установщик

| Компонент | Назначение |
|---|---|
| Next.js standalone-сервер | Бэкенд + фронтенд |
| Electron runtime | Десктоп-оболочка |
| Prisma engine + клиент | Работа с локальной SQLite |
| Встроенный справочник лиг | 46 лиг из ТЗ (засевается при первом запуске) |
| SQLite | Локальная БД (создаётся при первом запуске) |

## Куда сохраняются данные

| Платформа | Путь к БД |
|---|---|
| Windows | `%APPDATA%\SmartDraw\smartdraw.db` |
| macOS | `~/Library/Application Support/SmartDraw/smartdraw.db` |
| Linux | `~/.config/SmartDraw/smartdraw.db` |

Бэкап/перенос между ПК — через **Настройки → Локальная база данных → Экспорт в файл**.

## Частые вопросы

**Q: Workflow упал с ошибкой. Что делать?**
Откройте упавший шаг, посмотрите лог. Чаще всего проблема в нехватке памяти — перезапустите workflow. Если ошибка повторяется — создайте Issue в репозитории с текстом ошибки.

**Q: Можно ли сделать автосборку при пуше?**
Да — workflow уже настроен на запуск при создании тега `v*` (например `v1.0.0`). После тега автоматически создастся GitHub Release с готовыми установщиками.

**Q: Антивирус ругается на .exe?**
Это ложное срабатывание (электронные установщики без цифровой подписи часто вызывают подозрения). Добавьте файл в исключения или соберите локально (Способ 2). Для продакшн-распространения нужна code signing certificate (~$200/год).

**Q: Как обновлять приложение?**
Залейте новый коммит → запустите workflow → скачайте новый установщик → установите поверх старого. БД сохранится. Для автосборки при релизе — создайте тег `v1.1.0`, GitHub автоматически соберёт Release.
